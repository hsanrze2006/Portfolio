# Personal Portfolio Website

A multi-page personal portfolio website created to introduce myself, showcase my projects, and share information about my skills and web development journey.

## ✨ Pages and Sections

- **Home:** Introduction and featured projects
- **Projects:** Project showcase
- **About Me:** Personal introduction and background
- **Contacts:** Contact information and social links
- **Responsive styling:** CSS rules for different screen sizes

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox and responsive CSS
- Font Awesome for icons
- GitHub Pages for deployment

The homepage also uses a small inline JavaScript interaction for the logo.

## 📂 Project Structure

```text
portfolio/
├── assets/
├── css/
│   ├── reset.css
│   ├── common.css
│   ├── style.css
│   └── responsive.css
├── pages/
├── index.html
└── README.md
```

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/hsanrze2006/portfolio.git
   cd portfolio
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
