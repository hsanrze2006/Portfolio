## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/hsanrze2006/Portfolio2nd.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio2nd
   ```

3. Open `index.html` in your browser.
